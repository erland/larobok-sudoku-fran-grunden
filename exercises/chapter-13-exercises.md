# Övningar till kapitel 13: Nästa steg

## Syfte

Övningarna hjälper dig att planera fortsatt träning efter boken och använda strategierna på ett lugnt, metodiskt sätt.

## Övning 1: Välj rätt nivå

Fyll i ett lämpligt nästa steg.

| Situation | Rekommenderat nästa steg |
|---|---|
| Jag löser enkla sudoku snabbt men gör slarvfel. |  |
| Jag fastnar ofta på medelsvåra sudoku men förstår ledtrådarna. |  |
| Jag fastnar tidigt och förstår inte facit. |  |
| Jag löser medelsvåra sudoku lugnt och kan förklara mina steg. |  |

### Facitförslag

| Situation | Rekommenderat nästa steg |
|---|---|
| Jag löser enkla sudoku snabbt men gör slarvfel. | Fortsätt med enkla eller lätt medelsvåra sudoku och träna kontrollpunkter. |
| Jag fastnar ofta på medelsvåra sudoku men förstår ledtrådarna. | Fortsätt på samma nivå men använd små ledtrådar och skriv egna förklaringar. |
| Jag fastnar tidigt och förstår inte facit. | Gå tillbaka till enklare nivå och repetera kandidater, singlar och scanning. |
| Jag löser medelsvåra sudoku lugnt och kan förklara mina steg. | Prova lite svårare sudoku eller fokusera på par och låsta kandidater. |

## Avslutande uppgift

Välj ett sudoku på en nivå som känns lagom svår. Lös det långsamt och skriv efteråt:

- tre säkra placeringar du gjorde
- en kandidat du tog bort
- en kontrollpunkt som hjälpte dig
- ett misstag du undvek
- en strategi du vill träna mer på
